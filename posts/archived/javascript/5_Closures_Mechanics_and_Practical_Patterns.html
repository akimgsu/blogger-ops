Part 5: Closures — Mechanics, Practical Patterns, and Pitfalls

A closure is a function paired with its definition-time Lexical Environment. Inner functions can access outer variables after the outer function returns.

1. Basic Example

function makeCounter() {
  let count = 0;
  return function increase() {
    count += 1;
    return count;
  };
}
const counter = makeCounter();
counter(); // 1
counter(); // 2

2. Why It Works

The engine keeps environment records alive on the heap for free variables still referenced by the closure.

3. Practical Uses

function createWallet(initial = 0) {
  let balance = initial;
  return {
    deposit(amount) { balance += amount; return balance; },
    getBalance() { return balance; },
  };
}

function debounce(fn, delay) {
  let timerId;
  return function (...args) {
    clearTimeout(timerId);
    timerId = setTimeout(() => fn.apply(this, args), delay);
  };
}

4. Classic Loop Bug

for (var i = 0; i < 3; i++) setTimeout(() => console.log(i), 0); // 3 3 3
for (let i = 0; i < 3; i++) setTimeout(() => console.log(i), 0); // 0 1 2

5. Memory Cost

Closures retain outer environments. Capture only what you need and detach listeners/timers when done.

function createHandler(hugeData) {
  const id = hugeData.id;
  return () => console.log(id);
}

Chapter Summary

  • Closure = function + definition-time lexical environment.
  • Outer functions can finish while free variables remain reachable.
  • Use for encapsulation, currying/partial application, events/debounce.
  • Prefer let for loop + async callbacks.
  • Minimize retained scope and unsubscribe to avoid memory pressure.
