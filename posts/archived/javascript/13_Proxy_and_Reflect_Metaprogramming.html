Part 13: Metaprogramming with Proxy and Reflect

Proxy intercepts default object operations via traps; Reflect forwards the default behavior safely.

1. Basic Proxy

const proxy = new Proxy(target, {
  get(obj, prop, receiver) {
    return Reflect.get(obj, prop, receiver);
  },
  set(obj, prop, value, receiver) {
    return Reflect.set(obj, prop, value, receiver);
  },
});

2. Practical Patterns

function withDefault(obj, defaultValue = 0) {
  return new Proxy(obj, {
    get(target, prop, receiver) {
      return prop in target ? Reflect.get(target, prop, receiver) : defaultValue;
    },
  });
}

function reactive(obj, onChange) {
  return new Proxy(obj, {
    set(target, prop, value, receiver) {
      const prev = target[prop];
      const ok = Reflect.set(target, prop, value, receiver);
      if (ok && prev !== value) onChange(prop, value, prev);
      return ok;
    },
  });
}

3. Pitfalls and Revocable Proxies

  • proxy !== target
  • Hot-path performance cost
  • Inconsistent traps break introspection APIs
  • Private fields are hard to intercept
const { proxy, revoke } = Proxy.revocable({ secret: 42 }, {});
revoke(); // further access throws

Chapter Summary

  • Proxy intercepts operations via traps.
  • Reflect forwards defaults; pass receiver correctly.
  • Useful for validation, logging, defaults, and reactivity sketches.
  • Watch identity, performance, and trap consistency.
  • Proxy.revocable can withdraw access.
