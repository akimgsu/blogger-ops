Part 12: Iterables and Generators

for...of and spread work across arrays, maps, sets, and strings because of the Iterable Protocol. Generators make it easy to implement—and enable lazy evaluation.

1. The Protocol

const it = arr[Symbol.iterator]();
it.next(); // { value, done }

2. Custom Iterables and Generators

function* rangeGen(from, to) {
  for (let i = from; i <= to; i++) yield i;
}
console.log([...rangeGen(1, 3)]); // [1, 2, 3]

function* b() { yield* a(); yield 3; }

3. Lazy Sequences

function* infiniteIds(start = 1) {
  let id = start;
  while (true) yield id++;
}
function* take(n, iterable) {
  let i = 0;
  for (const item of iterable) {
    if (i++ >= n) return;
    yield item;
  }
}

4. Async Generators

async function* fetchPages(url) {
  let next = url;
  while (next) {
    const data = await (await fetch(next)).json();
    yield data.items;
    next = data.nextUrl;
  }
}
for await (const items of fetchPages("/api?page=1")) { /* ... */ }

Chapter Summary

  • Iterables expose iterators via Symbol.iterator.
  • for...of and spread rely on this protocol.
  • function*/yield implement iterators lazily.
  • yield* delegates; async generators power async streams.
  • Pair infinite sequences with take for safe consumption.
