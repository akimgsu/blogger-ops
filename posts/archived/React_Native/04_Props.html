04. Passing Data (Props)

So far, we have learned how to create components and organize our UI. However, an app needs data to actually function! Today, we will learn about Props, the core concept for passing data between components.

1. What are Props?

Props is short for 'Properties'. Simply put, it refers to data passed down from a parent component to a child component.

As your app grows, you will break down your screens into smaller, manageable components. Invariably, you will need to hand data over from one component to another. That is exactly what Props are used for.

One-Way Data Flow

One of the most critical principles in React and React Native is that "data flows top-down". You can only pass Props from a parent to a child, and the child cannot directly alter the parent's data. This is known as one-way data binding.

💡 Core Metaphor: "Genetics (DNA)"
Think of Props as the DNA a parent passes to a child. The child inherits characteristics (data) like eye color or hair color and displays them, but the child cannot spontaneously change the genes they inherited.

2. Why Use Props? (Maximizing Reusability)

The biggest reason to use Props is to maximize the reusability of your components.

If you need an 'OK', 'Cancel', and 'Submit' button, it would be highly inefficient to build three entirely separate button components. Instead, you create just one foundational button component and pass different colors and texts via Props. This keeps your code incredibly clean and efficient.

3. Practice: Building a Reusable Custom Button Component

Let's create a single button component and reuse it multiple times by passing different Props from the parent.

Child Component (CustomButton.js)

import React from 'react';
import { TouchableOpacity, Text, StyleSheet } from 'react-native';

// We receive the props object as a parameter (using destructuring)
export default function CustomButton({ title, bgColor }) {
  return (
    <TouchableOpacity style={[styles.button, { backgroundColor: bgColor }]}>
      <Text style={styles.buttonText}>{title}</Text>
    </TouchableOpacity>
  );
}

const styles = StyleSheet.create({
  button: {
    padding: 15,
    borderRadius: 8,
    alignItems: 'center',
    marginVertical: 10,
  },
  buttonText: {
    color: '#fff',
    fontSize: 16,
    fontWeight: 'bold',
  }
});

Parent Component (App.js)

import React from 'react';
import { View, StyleSheet } from 'react-native';
import CustomButton from './CustomButton';

export default function App() {
  return (
    <View style={styles.container}>
      {/* 
        Calling the child component (CustomButton) 
        and passing 'title' and 'bgColor' as Props. 
      */}
      <CustomButton title="OK" bgColor="#007AFF" />
      <CustomButton title="Cancel" bgColor="#FF3B30" />
      <CustomButton title="Submit" bgColor="#34C759" />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    padding: 20,
  },
});

Through this exercise, we wrote the structure for a button component just once! Yet, depending on the Props (title, bgColor) handed down by the parent component, we successfully generated three completely distinct buttons.

Chapter Summary

  • Definition of Props: Data passed from a parent component down to a child component.
  • One-Way Flow: Data only travels from top to bottom. Child components can only read the Props they receive, they cannot modify them directly (like inheriting DNA).
  • Reusability: When you need elements with identical UI structures but different data, you build a single component and swap out the Props, greatly maximizing code reusability.
