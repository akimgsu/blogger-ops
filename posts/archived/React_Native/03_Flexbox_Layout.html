03. Mobile Layouts and Flexbox (StyleSheet)

To arrange and style UI components in React Native, you must fully grasp its layout system. Today, we'll explore Flexbox and StyleSheet, the core tools for constructing screens in mobile apps.

1. Differences Between CSS and RN StyleSheet

In web development, we use CSS (Cascading Style Sheets) to style elements. React Native uses a similar approach, but you cannot simply copy and paste CSS code. Instead, we use the StyleSheet API, which defines styles as JavaScript objects.

Here are the key differences:

  • CamelCase: Properties like background-color in CSS become backgroundColor in RN (using capitalization instead of hyphens).
  • No Units: Most dimensions (width, height, padding, etc.) are entered as numbers without units (like px). These numbers automatically translate to density-independent pixels (dp) on mobile screens.
  • StyleSheet.create(): We use this built-in method to cache style objects, which improves rendering performance.

2. The Mobile Essential: Flexbox

Mobile devices come in all shapes and sizes. From small smartphones to wide tablets, your UI needs to look good and avoid breaking on any screen. The solution to this is Flexbox.

💡 Core Metaphor: "Bento Box Dividers"
Flexbox doesn't lock elements into hard-coded pixels. Instead, it acts like flexible bento box dividers that smoothly stretch and shrink, automatically adjusting proportions based on the available screen real estate.

RN Flexbox Default Direction (Column)

In standard web CSS, the default flex-direction is horizontal (row). However, in React Native, the default direction is vertical (column).

Why? Because the smartphones we use are vertically oriented. Stacking elements from top to bottom is the most natural flow for a mobile UI.

Top 3 Flexbox Properties

  1. flex: Determines the proportion of space an element takes up. Setting flex: 1 makes it consume all remaining available space.
  2. justifyContent: Aligns elements along the primary axis (e.g., center, space-between).
  3. alignItems: Aligns elements along the cross axis.

3. Practice: Building an Instagram-Style Responsive Layout

Let's use Flexbox to create an Instagram-style feed layout featuring a top header, an image area, and a bottom action bar.

import React from 'react';
import { View, Text, Image, StyleSheet } from 'react-native';

export default function FeedPost() {
  return (
    <View style={styles.cardContainer}>
      
      {/* 1. Top Header Area (Row alignment) */}
      <View style={styles.header}>
        <Image source={{ uri: 'https://via.placeholder.com/40' }} style={styles.avatar} />
        <Text style={styles.username}>react_native_master</Text>
      </View>

      {/* 2. Main Image Area */}
      <Image source={{ uri: 'https://via.placeholder.com/400' }} style={styles.mainImage} />

      {/* 3. Bottom Action Buttons (Row alignment) */}
      <View style={styles.actions}>
        <Text style={styles.icon}>❤️</Text>
        <Text style={styles.icon}>💬</Text>
        <Text style={styles.icon}>✈️</Text>
      </View>
      
      <Text style={styles.likes}>1,024 Likes</Text>
      
    </View>
  );
}

const styles = StyleSheet.create({
  cardContainer: {
    flex: 1, // Uses all available space
    backgroundColor: '#fff',
    marginBottom: 20,
  },
  header: {
    flexDirection: 'row', // Changes default column to row for horizontal layout
    alignItems: 'center', // Vertically centers items
    padding: 10,
  },
  avatar: {
    width: 40,
    height: 40,
    borderRadius: 20,
    marginRight: 10, // Spacing between avatar and name
  },
  username: {
    fontWeight: 'bold',
    fontSize: 16,
  },
  mainImage: {
    width: '100%',
    height: 400, // You can use fixed heights or an aspect ratio
  },
  actions: {
    flexDirection: 'row', // Aligns action buttons horizontally
    padding: 10,
  },
  icon: {
    fontSize: 24,
    marginRight: 15, // Spacing between buttons
  },
  likes: {
    fontWeight: 'bold',
    paddingHorizontal: 10,
    marginBottom: 10,
  }
});

As you can see, by applying flexDirection: 'row', we grouped the profile picture and name horizontally, as well as the action icons. The main container retains the default column direction, stacking everything neatly from top to bottom.

Chapter Summary

  • Using StyleSheet: Uses a syntax similar to CSS but requires camelCase and unitless numbers for dimensions.
  • Mobile-Optimized Flexbox: Utilizes elastic Flexbox layouts that dynamically adapt to various screen sizes.
  • Default Axis is Column: Due to the vertical nature of mobile screens, elements stack downwards (column) by default. You only switch to flexDirection: 'row' when horizontal alignment is specifically needed.
