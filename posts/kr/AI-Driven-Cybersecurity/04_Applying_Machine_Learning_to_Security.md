# 04. Applying Machine Learning to Security (보안에 머신러닝 적용하기)

인공지능의 핵심 동력인 머신러닝(Machine Learning)은 명시적인 프로그래밍 없이 통계적 모델을 활용해 데이터로부터 스스로 학습합니다. 특히 보안 분야에서는 데이터의 형태와 해결하려는 문제에 따라 다양한 머신러닝 알고리즘이 적용됩니다. 이번 장에서는 보안 문제를 해결하기 위한 머신러닝의 접근 방식들을 자세히 살펴봅니다.

## 1. Choosing the Right ML Approach (올바른 ML 접근 방식 선택하기)

머신러닝은 딥러닝(인간의 두뇌 신경망을 모방한 다층 신경망)과 같은 심화된 형태를 포함하는 AI의 핵심 기능입니다. 사이버 보안에서 사용되는 데이터는 크게 두 가지로 나뉩니다.

- **Labeled Data (레이블링된 데이터):** 정상/악성 등 정답이 태그되어 있는 데이터. 이를 활용하는 학습 방식을 **지도 학습(Supervised Learning)**이라고 합니다.
- **Unlabeled Data (레이블링되지 않은 데이터):** 정답이 없는 데이터. 이 데이터에서 숨겨진 구조나 패턴을 찾아내는 방식을 **비지도 학습(Unsupervised Learning)**이라고 합니다.

어떤 머신러닝 알고리즘을 선택할지는 데이터의 유형과 해결하고자 하는 보안 문제(미래 이벤트 예측, 악성 여부 분류, 이상 징후 탐지, 적대적 합성 데이터 생성 등)에 따라 결정됩니다.

## 2. Prediction by Regression (회귀를 통한 예측)

사이버 보안에서 회귀(Regression) 문제는 알려진 데이터를 기반으로 '미래의 연속적인 값이나 이벤트'를 예측하는 데 사용됩니다. 예를 들어, 특정 봇넷 공격의 트래픽 강도를 예측하거나, 조작된 IoT 디바이스에서 발생하는 비정상적인 온도/전력 수치를 예측할 수 있습니다.

- **선형 회귀 (Linear Regression):** 입력 변수와 출력 변수 간의 관계를 단순한 직선으로 모델링하는 가장 이해하기 쉬운 알고리즘입니다.
- **고급 회귀 모델:** 서포트 벡터 회귀(SVR), 랜덤 포레스트(Random Forest), 의사결정 트리(Decision Trees), 그리고 복잡한 비선형 패턴을 모델링할 수 있는 인공 신경망(Regression ANN) 등이 활용됩니다.

## 3. Classification: Intruder or Not (분류: 침입자인가 아닌가)

숫자(연속값)를 예측하는 회귀와 달리, 분류(Classification) 알고리즘은 새로운 데이터를 미리 정의된 특정 '카테고리'로 분류합니다. 보안 영역에서는 수신된 이메일이 스팸(피싱)인지 정상인지 판단하거나, 특정 웹사이트나 트래픽이 악성(Malicious)인지 정상(Benign)인지를 식별하는 데 주로 쓰입니다.

가장 널리 사용되는 분류 알고리즘에는 다음이 포함됩니다:
- **로지스틱 회귀 (Logistic Regression):** 이름은 회귀지만 분류 문제에 쓰이는 기본 알고리즘입니다.
- **K-최근접 이웃 (K-Nearest Neighbors, KNN):** 데이터의 거리 유사성을 바탕으로 분류합니다.
- **서포트 벡터 머신 (Support Vector Machines, SVM)** 및 **나이브 베이즈 (Naive Bayes).**

## 4. Security Anomaly Detection (보안 이상 탐지)

레이블링된 데이터(정답)를 확보하는 것은 많은 시간과 비용이 듭니다. 이럴 때 **비지도 학습(Unsupervised Learning)**이 강력한 대안이 됩니다. 정답 없이도 데이터에서 유용한 인사이트를 찾아내기 때문입니다.

- **클러스터링 (Clustering):** 비슷한 특성을 가진 데이터 포인트들을 그룹화합니다.
- 패턴 인식(자연스러운 그룹 찾기)에는 **K-평균(K-means)** 알고리즘이 자주 쓰이며, 정상적인 패턴에서 크게 벗어난 데이터 포인트를 찾아내는 '이상 탐지(Anomaly Detection)'에는 **DBSCAN**이나 **베이지안 가우시안 혼합 모델(Bayesian GMM)**이 탁월한 성능을 발휘합니다. 이를 통해 알려지지 않은 제로데이 공격을 탐지해낼 수 있습니다.

## 5. GAN, BERT, GPT, and More (최신 딥러닝 모델의 활용)

자연어 처리와 생성형 미디어 분야에서 혁신을 일으킨 최신 모델들 또한 보안에 다양하게 적용되고 있습니다.

- **GPT (Generative Pre-trained Transformer):** 방대한 텍스트 데이터에 대한 '사전 학습(Pre-training)'과 특정 작업을 위한 '미세 조정(Fine-tuning)'의 두 단계를 거칩니다. 언어의 문맥을 깊이 이해하는 트랜스포머 아키텍처를 기반으로 하여, 피싱 텍스트 분석이나 보안 로그 요약 등에 사용됩니다.
- **GAN (Generative Adversarial Networks):** 가짜 데이터를 생성하는 '생성자(Generator)'와 진짜/가짜를 구별하는 '판별자(Discriminator)'가 서로 경쟁하며 학습합니다. 이를 통해 공격자는 진짜와 구분하기 힘든 딥페이크나 합성 악성코드를 만들어낼 수 있으며, 방어자는 이를 탐지하는 모델을 훈련시킬 수 있습니다.
- **에이전트 AI의 발전:** 최근에는 스테이블 디퓨전(Stable Diffusion) 같은 확산 모델(Diffusion models)이 미디어 생성의 주류로 자리잡고 있습니다. 에이전트 AI는 이러한 생성 기술의 기반 위에 '다단계 추론, 계획, 자율적 실행(Acting)' 능력을 더해 한 차원 높은 수준의 대응 체계를 구축하고 있습니다.

---

### Chapter Summary (챕터 요약)
- **ML 접근 방식:** 데이터의 라벨 유무(지도 학습 vs 비지도 학습)와 보안 목표(분류, 회귀, 클러스터링)에 따라 적절한 알고리즘을 선택해야 합니다.
- **예측과 분류:** 회귀(Regression)는 미래의 공격 강도나 수치를 예측하고, 분류(Classification)는 위협이 정상인지 악성인지를 카테고리화 합니다.
- **비지도 학습의 힘:** 클러스터링 기법(K-means, DBSCAN)은 레이블 없이도 데이터의 숨겨진 이상 징후를 탐지해 제로데이 위협 방어에 필수적입니다.
- **최신 딥러닝 기술:** GPT, GAN, 확산 모델 등은 매우 정교한 합성 데이터(또는 위협)를 생성하며, AI 에이전트는 이를 기반으로 자율적인 보안 조치를 계획하고 실행합니다.
