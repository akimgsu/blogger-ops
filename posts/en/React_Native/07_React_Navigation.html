07. Navigating Between Screens (React Navigation)

Most applications are not made of just a single screen. Like Instagram or WhatsApp, apps have multiple screens, and users navigate through them by tapping buttons. Today, we will explore React Navigation, the standard library for handling screen transitions (routing) in React Native.

1. Understanding Mobile App Navigation

On the web, clicking a link (an <a> tag) loads an entirely new HTML page. However, mobile apps operate differently because they are not browsers.

Mobile app navigation generally takes the following forms:

  1. Stack: Placing a new screen on top of the current screen. (The most fundamental method)
  2. Tab: Switching between screens using a tab bar located at the bottom or top.
  3. Drawer: A menu that slides out from the side of the screen like a drawer.

2. Stack Navigation and Passing Parameters

Let's look closer at the most commonly used type: Stack Navigation.

💡 Core Metaphor: "Stacking Cards"
Imagine stacking playing cards on a desk.
When navigating to a new screen (navigation.navigate): You lay a new card on top of the existing screen.
When going back (navigation.goBack): You discard the card on the very top, revealing the existing screen underneath.

When you transition, you don't just change the view; you can also pass data (parameters) along. For example, if a user clicks 'Apple' on a product list screen, you pass the data 'Apple' to the details screen so it knows to display the apple details.

3. Practice: Building a Login ↔ Main Tab Navigation Structure

Let's build a practical app structure where a user starts at a Login screen (Stack) and, upon logging in, transitions to a Main interface featuring bottom tabs (Home and Settings).

(Note: To run this, you must install libraries like @react-navigation/native, @react-navigation/native-stack, and @react-navigation/bottom-tabs.)

import React from 'react';
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { createBottomTabNavigator } from '@react-navigation/bottom-tabs';
import { View, Text, Button, StyleSheet } from 'react-native';

const Stack = createNativeStackNavigator();
const Tab = createBottomTabNavigator();

// --- Screen Components ---

// 1. Login Screen
function LoginScreen({ navigation }) {
  return (
    <View style={styles.center}>
      <Text style={styles.text}>Login Screen</Text>
      {/* Navigates to MainTab (Puts a new card on the stack) */}
      <Button title="Log In" onPress={() => navigation.navigate('MainTab')} />
    </View>
  );
}

// 2. Home Screen (Tab 1)
function HomeScreen() {
  return (
    <View style={styles.center}>
      <Text style={styles.text}>🏠 Home Screen</Text>
    </View>
  );
}

// 3. Settings Screen (Tab 2)
function SettingsScreen() {
  return (
    <View style={styles.center}>
      <Text style={styles.text}>⚙️ Settings Screen</Text>
    </View>
  );
}

// --- Navigator Configurations ---

// Bottom Tab Navigator (Groups Home and Settings)
function MainTabNavigator() {
  return (
    <Tab.Navigator>
      <Tab.Screen name="Home" component={HomeScreen} />
      <Tab.Screen name="Settings" component={SettingsScreen} />
    </Tab.Navigator>
  );
}

// Top-level Stack Navigator (Groups Login and the Tab Navigator)
export default function App() {
  return (
    // The container that manages our navigation tree
    <NavigationContainer>
      <Stack.Navigator initialRouteName="Login">
        <Stack.Screen name="Login" component={LoginScreen} />
        {/* Calling 'MainTab' renders the entire Tab Navigator as a screen */}
        <Stack.Screen 
          name="MainTab" 
          component={MainTabNavigator} 
          options={{ headerShown: false }} // Hides the stack header on the tab screens
        />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

const styles = StyleSheet.create({
  center: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  text: { fontSize: 24, marginBottom: 20 },
});

When you run this code, the 'Login Screen' appears first. Pressing 'Log In' places a new card (MainTab) on the stack, transitioning you to the main interface complete with a bottom tab bar to switch between Home and Settings!

Chapter Summary

  • React Navigation: The de facto standard library for handling screen transitions and routing in React Native apps.
  • Stack Navigation: Works like stacking cards. New screens are placed on top using navigation.navigate(), and the top screen is discarded when going back.
  • Combining Navigators: In real-world apps, you frequently combine Stacks, Tabs, and Drawers within a single app (e.g., nesting a Tab Navigator inside a Stack Navigator after a Login screen).
