05. State Management (State and useState)

In our previous session, we learned about Props, which is 'unchanging' data inherited from a parent. Today, we're diving into State, which is data that can 'change itself' from within a component. State and the useState hook are absolutely essential concepts for making your app interactive.

1. What is State and Why Do We Need It?

State is data that a component holds and manages on its own. As you use an app, the data visible on the screen constantly changes: numbers go up, text gets typed, checkboxes get toggled. If you change a standard variable (e.g., let count = 0;), will the screen automatically update? No. React does not re-draw the screen when standard variables change.

To force the screen to re-draw (re-render), you must notify React that a value has changed. This is precisely what State does. When a State value changes, React immediately refreshes the UI based on that new data.

💡 Core Metaphor: "The Chameleon's Mood"
If Props are inherited 'DNA', then State is like a chameleon's 'mood'. A chameleon autonomously alters its skin color (UI) in real-time depending on its environment or mood. Similarly, when a component's State (mood) changes, it automatically changes its screen (color).

2. How to Use the useState Hook

To create State in React Native, we use a React function (Hook) called useState.

import React, { useState } from 'react';

// Extracting values using array destructuring
const [count, setCount] = useState(0);
  • useState(0): The 0 inside the parentheses is the initial value of the State.
  • count: The variable holding the current State value.
  • setCount: The function used to update the State value. (You must use this function to change the value if you want the screen to update!)

3. Practice: Number Counter and Real-time Text Mini App

Let's use State to build a mini app where clicking a button increases a number, and typing in a box instantly mirrors the text on the screen.

import React, { useState } from 'react';
import { View, Text, TextInput, TouchableOpacity, StyleSheet } from 'react-native';

export default function StateApp() {
  // 1. State for managing the number (Initial value: 0)
  const [count, setCount] = useState(0);
  
  // 2. State for managing the typed text (Initial value: empty string)
  const [text, setText] = useState('');

  return (
    <View style={styles.container}>
      
      {/* Counter Section */}
      <View style={styles.section}>
        <Text style={styles.title}>Number Counter</Text>
        <Text style={styles.countText}>{count}</Text>
        
        {/* Using setCount to increase count by 1 */}
        <TouchableOpacity 
          style={styles.button} 
          onPress={() => setCount(count + 1)}
        >
          <Text style={styles.buttonText}>+ Increase by 1</Text>
        </TouchableOpacity>
      </View>

      <View style={styles.divider} />

      {/* Text Input Section */}
      <View style={styles.section}>
        <Text style={styles.title}>Real-time Text Mirror</Text>
        
        {/* onChangeText fires on every keystroke, updating the text State */}
        <TextInput 
          style={styles.input} 
          placeholder="Type something here..."
          onChangeText={(inputText) => setText(inputText)} 
        />
        
        {/* The screen immediately re-draws whenever the text State changes */}
        <Text style={styles.mirrorText}>You typed: {text}</Text>
      </View>

    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 20,
    justifyContent: 'center',
    backgroundColor: '#fff',
  },
  section: {
    alignItems: 'center',
  },
  title: {
    fontSize: 20,
    fontWeight: 'bold',
    marginBottom: 10,
  },
  countText: {
    fontSize: 40,
    color: '#007AFF',
    marginBottom: 10,
  },
  button: {
    backgroundColor: '#007AFF',
    padding: 15,
    borderRadius: 8,
  },
  buttonText: {
    color: '#fff',
    fontWeight: 'bold',
  },
  divider: {
    height: 1,
    backgroundColor: '#ddd',
    marginVertical: 30,
  },
  input: {
    width: '100%',
    borderColor: '#ccc',
    borderWidth: 1,
    padding: 10,
    borderRadius: 5,
    marginBottom: 10,
  },
  mirrorText: {
    fontSize: 16,
    color: '#555',
  }
});

If you run this code, you will see the number go up every time you press the button, and the text below the input box change in real-time as you type on the keyboard. This is the sheer power of triggering screen updates (Re-rendering) via State!

Chapter Summary

  • What is State?: Dynamic data that a component independently manages and updates internally.
  • Re-rendering: Unlike normal variables, when a State value is modified (via setState), React detects the change and freshly re-draws the UI.
  • useState Hook: Used in the format const [valueVar, modifierFunc] = useState(initialValue);. You must safely update the value strictly through the modifier function.
