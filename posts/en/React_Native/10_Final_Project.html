2. Practice: Building the 'Weather Todo' App

Let's mobilize everything we've learned to create a 'Weather-integrated Todo App' that displays the current weather and allows users to add and delete tasks.

Key Features & Applied Concepts

  • API (fetch): Displaying current weather at the top (OpenWeather API).
  • State (useState): Managing the text input and the array of todo items.
  • Lifecycle (useEffect): Fetching weather data exactly once when the app launches.
  • List Optimization (FlatList): Rendering a massive list of tasks without lag.
  • Props: Reusing custom button components (like the delete button).

Core Code Structure (App.js)

import React, { useState, useEffect } from 'react';
import { View, Text, TextInput, TouchableOpacity, FlatList, StyleSheet, SafeAreaView } from 'react-native';

export default function WeatherTodoApp() {
  const [weather, setWeather] = useState('Loading weather...');
  const [task, setTask] = useState('');
  const [todoList, setTodoList] = useState([]);

  // 1. useEffect + API (Fetch Weather)
  useEffect(() => {
    // Simulating an API call
    setTimeout(() => {
      setWeather('☀️ Sunny (24°C)');
    }, 1000);
  }, []);

  // 2. State Mutation (Add Task)
  const addTask = () => {
    if (task.trim() === '') return;
    const newTask = { id: Date.now().toString(), text: task };
    setTodoList([...todoList, newTask]);
    setTask(''); // Clear input
  };

  // 3. State Mutation (Delete Task)
  const deleteTask = (id) => {
    setTodoList(todoList.filter(item => item.id !== id));
  };

  // 4. Render function for FlatList
  const renderTodoItem = ({ item }) => (
    <View style={styles.todoItem}>
      <Text style={styles.todoText}>{item.text}</Text>
      <TouchableOpacity onPress={() => deleteTask(item.id)} style={styles.deleteBtn}>
        <Text style={styles.deleteBtnText}>Delete</Text>
      </TouchableOpacity>
    </View>
  );

  return (
    <SafeAreaView style={styles.container}>
      {/* Header Area (Weather Display) */}
      <View style={styles.header}>
        <Text style={styles.headerText}>Today's Weather: {weather}</Text>
      </View>

      {/* Input Area */}
      <View style={styles.inputContainer}>
        <TextInput 
          style={styles.input} 
          placeholder="Enter a task" 
          value={task}
          onChangeText={setTask}
        />
        <TouchableOpacity style={styles.addBtn} onPress={addTask}>
          <Text style={styles.addBtnText}>Add</Text>
        </TouchableOpacity>
      </View>

      {/* List Area (Using FlatList) */}
      <FlatList 
        data={todoList}
        renderItem={renderTodoItem}
        keyExtractor={item => item.id}
        contentContainerStyle={{ padding: 20 }}
      />
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, backgroundColor: '#f5f5f5' },
  header: { padding: 20, backgroundColor: '#4A90E2', alignItems: 'center' },
  headerText: { color: 'white', fontSize: 18, fontWeight: 'bold' },
  inputContainer: { flexDirection: 'row', padding: 20, backgroundColor: 'white' },
  input: { flex: 1, borderWidth: 1, borderColor: '#ddd', padding: 10, borderRadius: 5, marginRight: 10 },
  addBtn: { backgroundColor: '#4A90E2', padding: 15, borderRadius: 5, justifyContent: 'center' },
  addBtnText: { color: 'white', fontWeight: 'bold' },
  todoItem: { flexDirection: 'row', justifyContent: 'space-between', padding: 15, backgroundColor: 'white', borderBottomWidth: 1, borderBottomColor: '#eee' },
  todoText: { fontSize: 16 },
  deleteBtn: { backgroundColor: '#FF3B30', paddingHorizontal: 10, paddingVertical: 5, borderRadius: 5 },
  deleteBtnText: { color: 'white' }
});

3. Basics of Deployment (Build) and App Icons

Once your app development is complete, you need to set up the app icon and build the app to upload it to stores (Play Store, App Store).

The Build Flow when using Expo:

  1. Set App Icon & Splash Screen: In your project's app.json file, replace the icon and splash.image paths with the beautiful graphics you created.
  2. Setup EAS (Expo Application Services): Install the tool via terminal using npm install -g eas-cli and log in with eas login.
  3. Configure Project: Run eas build:configure to set up your build configurations.
  4. Execute Build Command:
    • For Android (APK/AAB): eas build -p android
    • For iOS (IPA): eas build -p ios
  5. Once the build completes on Expo's servers, they provide a download link. You can install it on your device or upload it to the store's developer console to launch!
