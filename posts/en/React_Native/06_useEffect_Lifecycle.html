06. Side Effects and Component Lifecycle (useEffect)

As you build React Native apps, you'll need to do more than just draw screens. You'll need to fetch data from a server as soon as the app opens, start a timer, or track the device's GPS location. These tasks, which fall outside the scope of simple UI rendering, are called Side Effects. The primary Hook used to manage them is useEffect.

1. The Component Lifecycle

Just like living organisms, every React component has a lifecycle.

  1. Mount (Birth): When the component first appears on the screen.
  2. Update (Growth/Change): When State or Props change, causing the screen to re-render.
  3. Unmount (Death): When the component is completely removed from the screen.

useEffect allows us to execute specific code at these exact three moments.

💡 Core Metaphor: "Employee Timesheet"
Think of a component as an office employee.
- Mount (Clock In): They arrive, turn on the computer, and check emails (initial data fetch).
- Update (Working): The boss gives a new instruction (State change), so they adjust their work.
- Unmount (Clock Out): When leaving, they must turn off the computer and tidy up their desk (Clean-up). Otherwise, the electricity bill keeps running! (Memory leaks).

2. How to Use useEffect and the Dependency Array

useEffect accepts two arguments. The first is the function to execute, and the second is the Dependency Array.

import React, { useEffect, useState } from 'react';

useEffect(() => {
  // Task to execute (Side Effect)
  console.log('Component rendered!');

  return () => {
    // Clean-up function - Called right before Unmount or before the next Effect runs
    console.log('Clean-up complete!');
  };
}, [Dependency Array]);

3 Execution Conditions Based on the Dependency Array

  • [] (Empty Array): Executes only once when the component initially mounts. (Perfect for initial API fetching).
  • [state1, state2]: Executes every time the specified State or Props inside the array change.
  • Omitted Array: Executes on every single render. (Rarely used as it can cause severe performance issues.)

3. Practice: A Stopwatch Tied to the Lifecycle

Let's use useEffect to create a stopwatch that starts ticking every second when it renders, and cleans up the timer when it disappears.

import React, { useState, useEffect } from 'react';
import { View, Text, StyleSheet, Button } from 'react-native';

// 1. Stopwatch Component
function Stopwatch() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    // Start timer on Mount (Clock In)
    console.log('Stopwatch started!');
    const interval = setInterval(() => {
      setSeconds(prev => prev + 1);
    }, 1000);

    // Clean up timer on Unmount (Clock Out)
    return () => {
      console.log('Stopwatch stopped and cleaned up!');
      clearInterval(interval);
    };
  }, []); // Empty array ensures this effect only runs once on initial render

  return (
    <View style={styles.stopwatchContainer}>
      <Text style={styles.timeText}>{seconds} sec</Text>
    </View>
  );
}

// 2. Parent Component (Toggles the stopwatch on/off)
export default function App() {
  const [showStopwatch, setShowStopwatch] = useState(true);

  return (
    <View style={styles.container}>
      <Text style={styles.title}>useEffect Lifecycle Test</Text>
      
      {/* Renders (Mounts) Stopwatch only if showStopwatch is true */}
      {showStopwatch && <Stopwatch />}

      <Button 
        title={showStopwatch ? 'Turn Off (Unmount)' : 'Turn On (Mount)'} 
        onPress={() => setShowStopwatch(!showStopwatch)} 
      />
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
    padding: 20,
  },
  title: {
    fontSize: 20,
    fontWeight: 'bold',
    marginBottom: 20,
  },
  stopwatchContainer: {
    padding: 20,
    backgroundColor: '#e3f2fd',
    borderRadius: 10,
    marginBottom: 20,
  },
  timeText: {
    fontSize: 30,
    fontWeight: 'bold',
    color: '#1565c0',
  }
});

When you press the 'Turn Off' button, the <Stopwatch /> component is removed (Unmounted) from the screen, triggering the return () => clearInterval(interval); block. This ensures that the timer doesn't keep running invisibly in the background, effectively preventing memory leaks.

Chapter Summary

  • Lifecycle: The journey of a component as it appears (Mounts), changes (Updates), and disappears (Unmounts) from the screen.
  • useEffect Hook: Used to handle side effects (timers, API calls, subscriptions) that are outside standard UI rendering.
  • Dependency Array: Passing an empty array [] makes it run once. Passing variables makes it run whenever those specific variables change.
  • Clean-up Function: The function you return inside useEffect. It runs before the component is destroyed or before the effect re-runs, acting as your 'clocking out and tidying up' mechanism.
