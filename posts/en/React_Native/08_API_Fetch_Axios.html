08. Fetching External Data (Fetch / Axios API)

Most apps we use today don't operate in isolation. YouTube fetches a list of videos, and WhatsApp receives messages. The process of communicating with a server to exchange data is absolutely essential in app development. Today, we'll explore API Communication and Asynchronous Processing to pull in external data.

1. Understanding Synchronous vs. Asynchronous

Fetching data from a server takes time, depending on internet speed and server status. If your app froze (synchronous processing) while waiting for data, preventing the user from tapping anything, it would be a terrible user experience.

To solve this, JavaScript uses an Asynchronous approach.

💡 Core Metaphor: "The Restaurant Waiter"
- Synchronous: A waiter takes your order to the kitchen (server) and stands there blocking the door until your food (data) is ready. You sit there doing nothing.
- Asynchronous: The waiter drops the order in the kitchen and immediately goes to serve other tables or clean up. When the chef calls out that the food is ready, the waiter brings it to your table.

In your app, you request data (fetch) from the server. The app doesn't stop; it continues rendering the screen and handling other tasks. When the data arrives (the Promise resolves), it updates the screen with the new data. We use the async and await keywords to write this code cleanly.

2. Practice: Fetching Weather Data via OpenWeather API

Let's use the built-in fetch function to pull weather data for Seoul from the free OpenWeather API and display it. (Note: In a real environment, you need your own API Key.)

import React, { useState, useEffect } from 'react';
import { View, Text, StyleSheet, ActivityIndicator } from 'react-native';

export default function WeatherApp() {
  const [weather, setWeather] = useState(null);
  const [loading, setLoading] = useState(true);

  // Fetch data exactly once when the component mounts
  useEffect(() => {
    getWeather();
  }, []);

  // Asynchronous function to call the API (using the 'async' keyword)
  const getWeather = async () => {
    try {
      // Fetch data (the waiter places the order and waits for the response using 'await')
      // *Note: Replace with a valid URL and API key in a real app.
      const response = await fetch('https://api.openweathermap.org/data/2.5/weather?q=Seoul&appid=YOUR_API_KEY');
      
      // Convert the response data to JSON format
      const json = await response.json();
      
      // Save the fetched data into State
      setWeather(json);
    } catch (error) {
      console.error('Failed to fetch weather data:', error);
    } finally {
      // Whether successful or failed, set loading to false
      setLoading(false);
    }
  };

  return (
    <View style={styles.container}>
      {/* Show a spinning loading indicator until the data arrives */}
      {loading ? (
        <ActivityIndicator size="large" color="#0000ff" />
      ) : (
        <View style={styles.weatherBox}>
          <Text style={styles.city}>City: {weather?.name || 'Seoul'}</Text>
          <Text style={styles.temp}>
            {/* Mock conversion from Kelvin to Celsius */}
            Temp: { weather?.main?.temp ? (weather.main.temp - 273.15).toFixed(1) : '22.5' }°C
          </Text>
          <Text style={styles.desc}>
            Status: {weather?.weather[0]?.main || 'Clear'}
          </Text>
        </View>
      )}
    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, justifyContent: 'center', alignItems: 'center', backgroundColor: '#f0f8ff' },
  weatherBox: { alignItems: 'center', padding: 20, backgroundColor: 'white', borderRadius: 10, shadowColor: '#000', shadowOpacity: 0.1, shadowRadius: 10 },
  city: { fontSize: 24, fontWeight: 'bold' },
  temp: { fontSize: 30, color: '#ff4500', marginVertical: 10 },
  desc: { fontSize: 20, color: '#555' }
});

In this code, useEffect triggers the asynchronous getWeather function as soon as the app turns on. While waiting for the data, an ActivityIndicator (loading spinner) is shown. Once the communication completes (the await finishes), the State updates, and the actual weather information is drawn on the screen.

(Pro tip: In real-world applications, developers often use an external library called axios instead of fetch because it provides convenient features like automatic JSON conversion.)

Chapter Summary

  • Asynchronous Communication: A method that prevents the app from freezing while waiting for data (the waiter metaphor). Implemented using async and await syntax.
  • API Integration: Using fetch or axios to request data from an external server (API) and receiving the result (usually as JSON).
  • Loading States: Utilizing a loading State to display a spinner while data is being fetched, significantly improving the user experience.
