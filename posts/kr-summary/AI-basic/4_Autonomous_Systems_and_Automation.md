# Phase 4: Autonomous Systems & Automation 핵심 요약

*   **MCP (Model Context Protocol)**:
    *   AI 모델과 외부 도구(API, DB 등) 사이의 데이터 통신 규격을 표준화.
    *   플그인(Plugin)이나 도구 연동을 일관되고 안전하게 구축할 수 있도록 지원.
*   **AI Agent (에이전트)**:
    *   지시받은 목표를 위해 스스로 **계획(Planning)** -> **행동(Action: 도구 호출)** -> **관찰(Observation)** 과정을 반복하는 자율 AI. (ReAct 프레임워크 기반)
*   **Workflow Automation (워크플로우 자동화)**:
    *   다수의 전문 AI 에이전트들과 사내 백엔드 시스템(AWS, DB 등)을 체인처럼 연결.
    *   복잡한 비즈니스 프로세스(예: 고객 CS 처리망)를 무인 자동화하여 효율성을 극대화.
