# 04. OAuth 2.0 Background and Purpose - Summary

- **Password Anti-Pattern:** 서드파티에 실비밀번호를 넘기는 위험 패턴.
- **OAuth 목적:** 비밀번호 공유 없이 Scope 단위로 권한 위임·취소.
- **OAuth는 인가 프레임워크**이지, 단독 인증 프로토콜이 아님 (인증은 OIDC).
- **4역할:** Resource Owner, Client, Authorization Server, Resource Server.
- **Scope:** 최소 권한의 언어. 동의(Consent)와 Revoke가 핵심 통제 수단.
