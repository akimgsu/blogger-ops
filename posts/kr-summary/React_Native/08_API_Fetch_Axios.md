# 핵심 요약: 08. 외부 데이터 연동 (Fetch / Axios API)

- **비동기(Asynchronous) 처리의 필요성**
  - 서버에서 데이터를 가져오는 동안 앱이 멈추면 안 됨.
  - 💡 **핵심 비유**: 주방(서버)에 주문을 넣고, 요리가 나올 때까지 서서 기다리지 않고 다른 손님을 받는 **"식당의 웨이터"**.

- **API 호출 문법 (async / await)**
  - 함수 앞에 `async`를 붙여 비동기 함수로 선언.
  - 시간이 걸리는 통신 작업(예: `fetch`) 앞에 `await`를 붙여, 해당 줄이 완료될 때까지 코드를 멈추고 기다렸다가 다음 줄을 실행. (앱 전체가 멈추는 것이 아님!)

- **실습 포인트 (날씨 API 연동)**
  - `useEffect`를 이용해 화면이 켜지자마자(`[]` 빈 배열) `getWeather()` 비동기 함수 호출.
  - API 통신 중에는 `loading` State를 `true`로 두어 `<ActivityIndicator>`(로딩 스피너) 표시.
  - 데이터를 받으면 `setWeather()`로 State를 업데이트하고, `loading`을 `false`로 바꿔 결과 출력.
