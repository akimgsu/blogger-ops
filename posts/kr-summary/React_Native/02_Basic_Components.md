# 핵심 요약: 02. 기본 컴포넌트의 이해

- **HTML 태그 사용 불가 이유**
  - 모바일 OS는 HTML을 이해하지 못함. 브라우저 DOM 대신 네이티브 UI를 사용해야 하기 때문.
  
- **주요 컴포넌트 매핑 가이드**
  - `<div>` ➡️ **`<View>`**: 레이아웃을 나누고 다른 요소를 담는 컨테이너.
  - `<span>`, `<p>` ➡️ **`<Text>`**: 텍스트 표시에 사용. RN에서는 모든 글자를 반드시 `<Text>`로 감싸야 함.
  - `<input>` ➡️ **`<TextInput>`**: 사용자 키보드 입력을 받을 때 사용.
  - `<button>` ➡️ **`<Button>`** 또는 **`<TouchableOpacity>`**: 클릭(터치) 이벤트 처리.

- 💡 **핵심 비유**
  - 웹이 자유로운 빈 도화지라면, 모바일(RN)은 정해진 **"규격화된 레고 블록"**을 조립하는 과정.

- **실습 포인트 (프로필 카드)**
  - `<View>`로 전체 레이아웃 박스를 만들고, 그 안에 `<Image>`, `<Text>`, `<TextInput>`을 순차적으로 배치하여 UI 구성.
