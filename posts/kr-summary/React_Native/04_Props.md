# 핵심 요약: 04. 데이터 전달하기 (Props)

- **Props(Properties)란?**
  - 부모 컴포넌트가 자식 컴포넌트에게 전달하는 **데이터**.
  
- **단방향 데이터 흐름 (One-way Data Binding)**
  - 데이터는 오직 위(부모)에서 아래(자식)로만 흐름.
  - 자식은 Props를 읽을 수만 있고, 직접 변경(수정)할 수 없음.
  - 💡 **핵심 비유**: 자식이 스스로 바꿀 수 없는, 부모에게서 물려받은 **"유전자(DNA)"**.

- **Props의 존재 이유 (재사용성 극대화)**
  - UI 뼈대는 같지만 내용(텍스트, 색상 등)만 다른 요소가 필요할 때, 컴포넌트를 여러 개 만들지 않음.
  - 뼈대 컴포넌트를 하나 만들고 Props만 바꿔 끼워서 코드의 중복을 막고 효율성을 높임.

- **실습 포인트**
  - 자식 컴포넌트(`CustomButton`)에서 매개변수로 `props`를 받아 렌더링에 사용.
  - 부모 컴포넌트(`App`)에서 자식 태그의 속성처럼 데이터(`<CustomButton title="확인" />`)를 넘겨주는 패턴 숙지.
