# 핵심 요약: 07. 화면 이동하기 (React Navigation)

- **React Navigation 라이브러리**
  - 모바일 앱의 화면 전환(Routing)을 담당하는 표준 도구.

- **모바일 네비게이션의 3대 구조**
  1. **Stack (스택)**: 가장 기본적임. 💡 **핵심 비유**: 책상 위에 **"카드 쌓기"**. 새 화면은 위에 덮고, 뒤로가기는 맨 위 카드를 버림.
  2. **Tab (탭)**: 하단이나 상단의 탭 바를 눌러 화면 간 전환.
  3. **Drawer (드로어)**: 화면 측면에서 스와이프하여 나오는 서랍형 메뉴.

- **데이터(파라미터) 전달**
  - 화면을 이동할 때 `navigation.navigate('디테일', { id: 123 })` 형태로 데이터를 함께 전달하여 다음 화면에서 재사용 가능.

- **실습 포인트 (네비게이터 중첩)**
  - 하나의 앱에 여러 네비게이터를 합칠 수 있음.
  - 최상위 `Stack.Navigator`에 '로그인 화면'과 '하단 탭 묶음(`Tab.Navigator`)'을 자식으로 두어, 로그인 완료 후 탭 화면으로 넘기는 실무 패턴 학습.
