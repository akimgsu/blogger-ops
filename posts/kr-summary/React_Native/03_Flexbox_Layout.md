# 핵심 요약: 03. 모바일 레이아웃과 Flexbox (StyleSheet)

- **StyleSheet의 특징 (CSS와의 차이)**
  - 카멜케이스(CamelCase) 표기법 사용 (예: `backgroundColor`).
  - 크기 단위(`px`)를 생략하고 숫자로만 작성 (모바일 dp로 자동 변환).
  - 성능 최적화를 위해 `StyleSheet.create({})` 객체 형태로 묶어서 관리.

- **Flexbox 레이아웃의 핵심**
  - **왜 쓰는가?** 기기마다 화면 크기가 다르므로, 비율에 맞춰 공간을 동적으로 할당하기 위함.
  - 💡 **비유**: 크기가 자유자재로 조절되며 공간을 나누는 **"도시락 통의 칸막이"**.

- **기본 방향 (Column vs Row)**
  - 웹(CSS)은 기본이 `row`(가로)지만, **RN은 스마트폰 형태에 맞춰 `column`(세로)이 기본값**.
  - 가로 배치가 필요할 때만 명시적으로 `flexDirection: 'row'`를 선언함.

- **실습 포인트 (인스타그램 피드)**
  - 요소들을 세로로 쌓되, 프로필(사진+이름)과 버튼부(좋아요+댓글) 등 특정 묶음만 `flexDirection: 'row'`를 주어 가로로 배치하는 원리 학습.
