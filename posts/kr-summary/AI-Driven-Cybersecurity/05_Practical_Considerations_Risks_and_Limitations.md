# 05. Practical Considerations, Risks, and Limitations - Summary

- **AI는 만능이 아님:** 확률에 의존하며 명확한 설명(Explainability)이 부족한 블랙박스 모델 특성상 전문가의 개입과 통제가 필수적.
- **새로운 공격 표면(Attack Surface):** AI 모델 자체가 타겟이 되어 데이터 포이즈닝(무결성 훼손), 추론 공격(정보 유출) 등을 당할 수 있음.
- **창과 방패의 AI 경쟁:** 해커들 역시 AI를 악용해 CAPTCHA 우회, 대규모 맞춤형 피싱, 딥페이크 사칭 등을 자행하고 있음.
- **성공적인 도입 원칙:** 양질의 데이터 확보(Data readiness)가 최우선이며, 작고 명확한 목표에서 시작해 지속적으로 피드백 루프를 돌려야 함.
- **솔루션 도입 가이드:** 벤더 제품 평가 시 자체 데이터 활용 가능성, 기존 워크플로우 통합 여부, 내장(Built-in) 설계 유무, 데이터 프라이버시 정책을 반드시 점검할 것.
