# 04. Applying Machine Learning to Security - Summary

- **머신러닝과 데이터:** 보안에 ML을 적용하기 위해 정답이 있는 데이터(지도 학습)와 정답이 없는 데이터(비지도 학습)의 성격을 이해하고 접근해야 함.
- **회귀(Regression) 분석:** 트래픽 강도나 시스템 수치 등 연속적인 값을 예측하여 잠재적 보안 사고의 규모나 시기를 예측함.
- **분류(Classification) 모델:** 로지스틱 회귀, SVM 등을 사용해 이메일, 트래픽, 파일이 '정상'인지 '악성'인지 명확하게 구분함.
- **비지도 학습과 이상 탐지:** K-means, DBSCAN 등의 클러스터링으로 패턴을 묶고, 정상 궤도를 벗어난 비정상 행위(제로데이 등)를 찾아냄.
- **첨단 딥러닝 모델 (GPT, GAN):** 방대한 언어적 맥락을 이해(GPT)하거나, 생성자와 판별자의 경쟁(GAN)을 통해 정교한 딥페이크 등 합성 데이터를 생성함.
- **에이전트 AI로의 진화:** 단순 생성 모델을 넘어 다단계 추론과 자율적 방어 조치를 직접 계획 및 실행하는 단계로 발전 중.
